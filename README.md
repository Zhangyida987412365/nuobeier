# 经济学的答案 · 诺奖中文学习图谱

独立中文学习网站，覆盖 1969—2026 年 58 届诺贝尔经济学奖、101 位获奖者。每届包含获奖贡献、理论解释、假设案例、三种应用、两项局限、小练习与原始来源。另有 4 个教学实验、3 条学习路线、全文检索、年代/主题/金融关联筛选，以及仅保存于当前浏览器的收藏和学习进度。

## 本地运行

本网站没有第三方前端依赖，不需要 npm 安装或构建。

在本文件所在文件夹运行：

    python3 -m http.server 4173 --bind 127.0.0.1

然后打开 http://127.0.0.1:4173 。也可直接打开 index.html 离线浏览。

## 内容维护

编辑 content.json，运行以下命令进行结构校验并重新生成浏览器使用的 data.js：

    python3 scripts/build.py

生成后将 content.json 和 data.js 一起提交。文件中的 2026 年资料依据瑞典皇家科学院与瑞典央行官方公告。

## Vercel 与 GitHub 自动部署

将本文件夹内容放到一个独立 GitHub 仓库的根目录，在 Vercel 导入该仓库。项目类型选择 Other；根目录为仓库根目录，无安装步骤和构建步骤，输出目录为 . 。仓库已包含 vercel.json。

Vercel 的 Git 集成可让生产分支（通常为 main）推送触发生产部署，其他分支和拉取请求触发预览部署；以项目实际的 Git 与部署设置为准。本地 git commit 本身不会上传或部署，需要成功 push 到已连接的远程仓库。

## 模型边界

- 投资组合实验：两个假设资产、给定预期收益/波动/相关性、只做多、不加杠杆，使用单期均值—方差公式，不含费用、税和估计误差。
- 博弈实验：固定收益表的一次性同时行动游戏，不代表现实竞争的一般结论。
- 风险选择实验：比较金额期望值相同但风险分布不同的方案，不诊断个人决策能力。
- 银行实验：静态现金与贷款提前变现的算术，不是完整挤兑模型；不含资本、存款保险、央行和客户策略。

## 来源与使用

本站不是诺贝尔奖官方产品，也不使用官方奖章或学者照片。获奖事实来自官方公开资料，中文案例与教学说明为独立改写；每届保留原始来源。资料核验至 2026-11-06。应用分类不是官方分类，任何示例都不构成收益承诺或投资建议。

没有实时行情、券商连接、登录、收费或服务器端用户数据。当前浏览器的学习记录不会自动跨设备同步。
